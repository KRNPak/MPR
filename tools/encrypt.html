Encrypt staff files

Everything happens in this browser. Files are never uploaded anywhere. Close the tab when you're done.

Select Staff_Master, Staff_Budget and Staff_Actuals as .xlsx (recommended) or .csv files. You'll get matching .enc files to put in Data/FY20XX/.

    How this works

    Files are encrypted with AES-256-GCM. The key comes from your passphrase through PBKDF2-SHA256 with 600,000 iterations, which makes guessing slow. A long, random passphrase is still what protects the data, so use the Generate button and store the result in a password manager. Share it only with people who should see salaries.

    Use the same passphrase for all three files of a year. The dashboard still opens old-style files, but flags them until they're upgraded.
